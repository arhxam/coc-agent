# Knowledge base (read-only, shipped with coc-agent)

General Clash of Clans know-how that holds for any account. Your `memory/` is about *this* account;
these files are about the game. When the two disagree, **what you see in game wins**: record it in
`memory/lessons.md` (and improve these files upstream if you're a contributor).

| file | read it when |
|---|---|
| `principles.md` | always useful: the economy and time rules every good player follows |
| `upgrade_order.md` | writing or fixing `memory/upgrade_priorities.md`, after a Town Hall upgrade |
| `farming.md` | choosing a farming army and targets, or loot per attack is low |
| `attacks.md` | picking or fixing a deployment recipe for `memory/attack_playbook.md` |
| `builder_base.md` | `do_builder_base` is on |
| `side_modes.md` | helpers, Blacksmith, magic items, Clan Capital, Clan Games, events, donations |
| `ui_basics.md` | first run, or after a game update moved things |

Numbers in these files (costs, timers, limits) drift with game updates. Treat them as hints to verify.
