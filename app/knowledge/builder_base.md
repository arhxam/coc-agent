# Builder Base (only when `do_builder_base` is on)

- **Getting there:** the boat on the home village's shore → Builder Base. Back the same way. Record exact
  positions in `memory/ui_map.md` (the shoreline can be off-screen; pan first).
- **Each visit (keep it ~5–10 min):** collect the Gold Mine / Elixir Collector / Gem Mine bubbles and the
  **Elixir Cart** near the dock, start Builder Base builder jobs, keep the **Star Laboratory** busy, then battle.
- **Builders:** the Builder Base has its own builder(s) (and the O.T.T.O. / Master Builder setup in newer
  versions). Same rule as home: never idle; long jobs before long gaps.
- **Priorities:** the troops you actually use (Star Lab) and the Battle Machine first; then offense buildings;
  defenses; Builder Hall when the profile says so.
- **Battles:** free to start. Cheap loot up to the **daily star/loot bonus**. Then it's not worth the time unless
  the cart has room. Deploy along one side, then use hero abilities. Log with `"strategy": "bb-<army>"`.
- Same safety rules: confirm buttons must show gold/elixir, close gem "finish" buttons with X.
