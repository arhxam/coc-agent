# Profile: frugal (lowest token cost)

**Goal:** steady progress for the fewest model tokens. Every screenshot costs tokens, so each run is short
and does only what moves the account forward.

## Each run, in this order, then finish
1. Collect resources and free rewards (one tap each, no exploring).
2. Start an upgrade on every idle builder and a research in an idle lab. Prefer **long** jobs: fewer runs needed.
3. Only if a builder or the lab is waiting for loot: **one** attack (`attacks_per_run`, default 1) with a simple
   one-side army (see `app/knowledge/attacks.md`), taking the first decent base.
4. Walls only if a storage is nearly full.
5. Finish. Target 10 minutes or less.

## Rules to save tokens
- Read memory, plan the run from it, then act. Don't re-screenshot to confirm things you just saw.
- Use `zoom` on a small region instead of a new full screenshot to read a number.
- Schedule the next run for when the next builder or lab job finishes, not sooner. Long jobs = rare runs.
- Skip the Builder Base and side modes unless the owner turned them on.
- Keep memory edits short. Do the daily review in under a minute; the weekly review matters more.
