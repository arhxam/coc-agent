# Upgrade priorities

The agent keeps this file. On the first run, survey the base and rewrite the queue for the account's
Town Hall using `app/knowledge/upgrade_order.md` and the active profile. Start each run from the first
unchecked item it can afford.
Format: `- [ ] item (resource) - why` / `- [~] item [in progress until <time>]` / `- [x] item (date)`

## Rules of thumb
- Keep every builder busy. An idle builder costs more than a slightly worse choice.
- Follow the profile's weighting (offense / defense / walls / Town Hall timing).
- Walls are a separate track (walls.md), not in this queue.
