# Upgrade priorities (TH13)

The agent keeps this file. Start each run from the first unchecked item it can afford.
Format: `- [ ] item (resource) - why` / `- [~] item [in progress until <time>]` / `- [x] item (date)`

## Rules of thumb
- Keep every builder busy. An idle builder costs more than a slightly worse choice.
- Offense first: the war/farming army (Electro Dragon, Lightning, heroes, Clan Castle, Army Camps, Barracks/Spell Factory) makes everything else faster.
- Then key defenses: Eagle Artillery, Scattershot, Inferno Towers, X-Bows, Air Defenses, Wizard Towers, Archer/Cannon.
- Then storages (bigger bank = more buffer for builders) and resource buildings, then traps. Walls are a separate track (walls.md), not in this queue.
- Heroes use dark elixir. Keep one builder rotating on heroes if DE allows. Don't upgrade all heroes at once or attacks get weak.
